# Djigit

Статический концепт лендинга для агентства Djigit с акцентом на:

- разработку мобильных приложений;
- внутренние системы и CRM;
- понятную лидогенерацию через кейсы, FAQ и CTA.

## Состав проекта

- `index.html` — основная страница лендинга;
- `styles.css` — визуальная система и адаптив;
- `script.js` — мобильное меню, FAQ и базовые интеракции;
- `assets/djigit-logo.svg` — логотип.

## Как запустить локально

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 4173
```

После этого откройте `http://127.0.0.1:4173/`.
